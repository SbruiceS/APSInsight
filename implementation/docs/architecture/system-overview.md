# APSInsight System Overview

APSInsight is an agriculture-specialized data analytics and scientific computing platform developed by ASPF.

## Core Capabilities

- Dataset management and quality assessment
- Statistical analysis and experimental design
- High-performance numerical computing (C++)
- Machine learning and predictive analytics (Python)
- Geospatial analytics and remote sensing
- Sensor and information fusion
- Reproducible research workflows
- Agricultural domain models (farms, fields, crops, soil, experiments)

## Integration Boundaries

External ASPF systems (AgriQL, KutajKutambi AI, APSNetwork, Nityaga RTOS) connect via documented adapters, not by embedding unfinished systems into the core.

See component-boundaries.md and data-flow.md for details.
